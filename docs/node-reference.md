# Node reference

Generated by `tools/gen_node_reference.py` from the core metadata.

Common conventions: `channels` selects channels or a layer to process (`rgba`, `rgb`, `alpha`, a layer name such as `diffuse`, a channel such as `depth.Z`, or a comma separated list). Nodes with a `mask` input blend their result with `mix` x mask. `(un)premult by alpha` divides colour by rgba.alpha around the operation (pixels with alpha <= 1e-6 are left alone). Any numeric knob can be keyframed or driven by an expression (`frame`, other knobs as `knob`, `Node.knob`, `Node.knob.x`).

## Draw

### Roto

Animated Bezier shapes with variable feather, blend modes and motion blur, rasterized to a matte. Edit shapes in the viewer.

Shapes are edited in the viewer when the node is selected (toolbar in the properties panel): Bezier (click, drag for tangents, click the first point or Enter to close), rectangle, ellipse, select/transform with a bounding-box gizmo for several points, Ctrl+click on a curve to insert a point, Delete to remove, arrows to nudge (Shift x10), point-feather tool. Each shape has blend mode, opacity, invert, feather (signed distance falloff, smooth or linear) plus per-point feather, edge blur, motion blur samples/shutter and its own animated transform. Auto-key off: editing a frame without a key offsets all keys; auto-key on: edits create a key at the current frame.

Inputs: `bg`

| knob | type | default | notes |
|---|---|---|---|
| `output` | channel | rgba.alpha |  |
| `combine` | enum | replace (replace / over / max / multiply) |  |
| `rgb` | bool | 0 | Composite the colour below over rgb |
| `color` | color | 1, 1, 1 |  |
| `format` | xy | 1920, 1080 | Used when nothing is connected |
